# asdf-brunost

[Brunost](https://github.com/atomfinger/brunost) plugin for [asdf](https://asdf-vm.com) and [mise](https://mise.jdx.dev).

## Install

```sh
asdf plugin add brunost https://github.com/atomfinger/asdf-brunost
asdf install brunost latest
asdf global brunost latest
```

Or with mise:

```sh
mise use brunost@latest
```

## Use

Pin a version per project by adding a `.tool-versions` file:

```
brunost 1.0.0
```
